# NE3ULA Repository Instructions

Read `docs/AGENTS.md` before making changes; it contains the detailed repository instructions.

- Framer is the current public NE3ULA production website.
- `ne3ula.com` redirects through Cloudflare to Framer; do not change that redirect.
- `sveltekit-app/` is the canonical coded application within this repository, not the public production website.
- Work on feature branches and use review/approval gates.
- Do not change Supabase, deployments, DNS, Framer, Cloudflare, redirects, or production configuration without explicit approval.
